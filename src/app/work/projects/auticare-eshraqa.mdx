## Overview

AutiCare (Eshraqa) is a graduation project for a daily support web application for mothers of children with autism. The backend was developed collaboratively with AI and frontend teams under academic supervision.

## Backend work

- Implemented JWT authentication, legal-disclaimer acceptance, and a one-child-profile rule.
- Built REST APIs for daily tracking, a resource library, community posts, reactions, and comments.
- Added video upload support using presigned URLs.
- Developed moderation workflows with keyword scanning, pending and approved review states, and audit logging for admin and moderator roles.
- Applied Clean Architecture and Entity Framework Core with SQL Server.

## Technologies

C#, ASP.NET Core, Entity Framework Core, SQL Server, REST APIs, JWT, and Clean Architecture.

This project was developed as part of the Computers and Systems Engineering graduation project at Al-Azhar University in 2025–2026.

## Privacy and screening note

Personal account and child-profile details, community posts, and sample assessment results have been redacted in the portfolio screenshots. The assessment is an initial screening aid, not a medical diagnosis; families should consult a qualified specialist for evaluation.
