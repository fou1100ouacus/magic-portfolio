## Overview

AutiCare (Eshraqa) is a secure, AI-powered daily companion designed to empower mothers of autistic children with gentle, non-medical support for everyday caregiving. A mandatory disclaimer confirms that it is a daily encouragement tool, not a substitute for professional therapy or medical care.

## Daily support

- A two-to-five-minute check-in helps track routines such as sleep, meltdowns, sensory triggers, and positive moments, along with the mother's stress level.
- Mothers can upload private calming video moments and review text-based AI progress insights.
- A single-child profile and a practical resource library provide visual schedules and self-care ideas.
- An in-app AI companion offers daily encouragement.

## Safe community

The community uses moderation workflows and blocklist filtering to support safer interactions. A dedicated moderation console helps reviewers assess community posts. The interface supports English and Arabic, including right-to-left layout.

## Backend work

- Implemented JWT authentication, legal-disclaimer acceptance, and a one-child-profile rule.
- Built REST APIs for daily tracking, a resource library, community posts, reactions, and comments.
- Added video upload support using presigned URLs.
- Developed moderation workflows with keyword scanning, pending and approved review states, and audit logging for admin and moderator roles.
- Applied Clean Architecture and Entity Framework Core with SQL Server.

## Technologies

C#, ASP.NET Core, Entity Framework Core, SQL Server, REST APIs, JWT, and Clean Architecture.

This project was developed as part of the Computers and Systems Engineering graduation project at Al-Azhar University in 2025–2026.

## Privacy and screening note

Personal account and child-profile details, community posts, and sample assessment results have been redacted in the portfolio screenshots. The assessment is an initial screening aid, not a medical diagnosis; families should consult a qualified specialist for evaluation.
