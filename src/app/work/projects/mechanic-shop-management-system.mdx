## Overview

This training project provides backend workflows for an automotive repair shop, including customer and vehicle records, repair work orders, technician assignments, and service scheduling.

## Backend work

- Modeled customers, vehicles, repair task templates, and work orders, including VIN uniqueness and protected-delete rules.
- Implemented a work order lifecycle from scheduled through in progress to completed or cancelled, including automatic cancellation of no-shows after 15 minutes.
- Added scheduling rules to prevent technicians and service bays from being double-booked.
- Implemented manager and technician roles with authentication and role-based authorization.
- Organized the application with Clean Architecture and CQRS using MediatR, Entity Framework Core, and ASP.NET Core.

## Technologies

C#, .NET, ASP.NET Core, Entity Framework Core, SQL Server, Clean Architecture, CQRS, MediatR, Docker, and GitHub Actions.

This project was completed as part of the Metigator backend development training program in 2025.

Customer contact details, account email, and vehicle plate numbers are redacted in the portfolio screenshots.
